## 👨‍💻 About Me

I'm a software engineer from India, currently working as a **Graduate Trainee at UBS**, where I work on backend development using Java and Spring Boot.

My interests lie in building efficient backend systems, understanding how distributed applications work, and exploring the intersection of software engineering and AI.

- 🏦 Working on software engineering in the financial services industry.
- ⚡ Interested in backend performance, API design, databases, and system architecture.
- 🤖 Building AI-powered applications with LLMs, agents, and Model Context Protocol (MCP).
- 🛠️ Experienced with Java, Spring Boot, React, PostgreSQL, and cloud-native development tools.
- ✍️ Writing original poetry and building [Penned Paradox](https://github.com/ashishsaranshakya/poetry-blog), a platform for my writing.
- 🌱 Continuously learning about distributed systems, microservices, and AI engineering.

I enjoy understanding not just how something works, but *why it works that way*.
